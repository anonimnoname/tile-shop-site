# Сайт магазина плитки: 3D-конструктор, заказы с доставкой, админка

**На чём написано:** сайт — HTML, CSS и JavaScript (без фреймворков), 3D — библиотека three.js (WebGL);
сервер — Node.js без внешних библиотек. Программа для ноутбука (`tile-design-app`) — Flutter (Dart).

**Языки:** русский и узбекский (латиница). Кнопка **UZ / RU** в шапке. Перевод — `public/js/i18n.js`:
словарь фраз; названия плитки, которые вводятся по-русски, показываются латиницей автоматически.

- **Сайт** (`public/`): каталог, 3D-конструктор (ванная, кухня, комната/коридор, цоколь и двор),
  план пола любой формы, расчёт плитки по раскладке, корзина и оформление заказа.
- **Сервер** (`server.js`): отдаёт сайт, принимает заказы, хранит товары и настройки,
  присылает новые заказы в Telegram. Внешних зависимостей нет, нужен только Node.js 20+.
- **Админка** (`/admin`): вход по паролю. Заказы со статусами, товары (добавить, фото, цена,
  наличие, скрыть с сайта), настройки магазина, курс доллара.

## Запуск на своём компьютере
```bash
node server.js set-password   # один раз: задать пароль админки
node server.js                # сайт: http://127.0.0.1:3000, админка: http://127.0.0.1:3000/admin
```
Без сервера `public/index.html` тоже открывается: каталог берётся из `public/js/catalog.js`,
а заказ уходит в WhatsApp.

## Установка на сервер (VPS с Ubuntu 22/24) и домен
1. В панели регистратора домена создайте запись **A** на IP сервера (и `www`, если нужно).
2. На сервере:
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
   sudo apt install -y nodejs git caddy
   sudo git clone <адрес репозитория> /opt/tile-shop
   cd /opt/tile-shop && sudo node server.js set-password
   ```
3. Служба, чтобы сайт работал всегда и перезапускался сам — `/etc/systemd/system/tile-shop.service`:
   ```ini
   [Unit]
   Description=Tile shop
   After=network.target

   [Service]
   WorkingDirectory=/opt/tile-shop
   ExecStart=/usr/bin/node server.js
   Environment=PORT=3000
   # Секретный адрес админки: https://ваш-домен/kamron-panel (по /admin её не найти)
   Environment=ADMIN_PATH=kamron-panel
   # Необязательно: открывать админку только с этих IP (например, интернет магазина)
   # Environment=ADMIN_IPS=1.2.3.4
   # Уведомления о заказах в Telegram (необязательно):
   # Environment=TG_BOT_TOKEN=123456:ABC...
   # Environment=TG_CHAT_ID=123456789
   Restart=always
   User=root

   [Install]
   WantedBy=multi-user.target
   ```
   ```bash
   sudo systemctl enable --now tile-shop
   ```
4. HTTPS (сертификат Caddy получит и продлит сам) — `/etc/caddy/Caddyfile`:
   ```
   ваш-домен.uz, www.ваш-домен.uz {
       encode gzip
       reverse_proxy localhost:3000
   }
   ```
   ```bash
   sudo systemctl reload caddy
   ```
5. **Telegram-уведомления**: создайте бота у @BotFather (получите токен), напишите боту
   любое сообщение, узнайте свой chat id (например, у @userinfobot), впишите оба значения
   в службу, затем `sudo systemctl daemon-reload && sudo systemctl restart tile-shop`.
6. **Резервные копии**: всё важное лежит в `data/` (товары, заказы, настройки, пароль)
   и `public/uploads/` (фото). Копируйте эти две папки, например раз в день по cron:
   `tar czf /root/backup-$(date +%F).tgz -C /opt/tile-shop data public/uploads`.

Обновить сайт: `cd /opt/tile-shop && sudo git pull && sudo systemctl restart tile-shop`.
Папки `data/` и `public/uploads/` git не трогает.

## Перед запуском обязательно
- В админке → **Настройки**: название, телефоны, адрес и **год, с которого работает магазин**
  (на главной крупно пишется «N лет с плиткой»; сейчас там пример — 2010).
- **Товары**: сейчас в каталоге примеры. Замените на настоящие и загрузите фото каждой плиты.

## Структура сайта
- Главная — реклама магазина: 3D-витрина, сколько лет работаете, форматы в масштабе, стили, новинки.
- Меню (☰ справа): Главная, Конструктор, Новинки, Размеры (60×120, 75×150, 80×135), Каталог, Контакты.
- Форматы задаются в `public/js/catalog.js` (`window.SIZES`), стили там же (`window.STYLES`).

## Уведомления о заказах на ноутбук
1. Откройте админку на ноутбуке в Chrome или Edge (только по `https://`).
2. Нажмите **🔔 Включить уведомления** и разрешите. Придёт тестовое уведомление.
3. Новые заказы будут всплывать в углу экрана, даже если вкладка закрыта (браузер должен быть
   запущен; в Windows он работает в фоне). Щелчок по уведомлению открывает заказы.
   Повторите на каждом компьютере, где нужно получать заказы.

## Подтверждение и оплата заказов
Предоплаты нет. В карточке заказа кнопки **Подтвердить в WhatsApp / Telegram** открывают чат
с клиентом и готовым сообщением: состав заказа, сумма, адрес и реквизиты для перевода.
Реквизиты (карта, счёт) задаются в **Настройках** админки и на сайте не показываются.
Статусы: Новый → Подтверждён → Оплачен → В доставке → Выполнен.

## Программа для магазина (ноутбук + ТВ)
Репозиторий `tile-design-app`: та же 3D-программа для Windows, работает без интернета,
каталог берёт с этого сайта (адрес вписывается в её Настройках).

## Как пользоваться админкой
- **Товары → + Добавить товар.** Название, размер, цена за м², сколько м² в коробке, где можно класть.
  Загрузите фото **одной плитки, снятой ровно сверху**: оно обрежется под размер и будет видно в 3D.
- **Каждый месяц.** Чего нет — снимите «В наличии» (покажется «под заказ»). Что больше не возите —
  снимите «На сайте». Кнопка «Копия» удобна, когда приходит та же плитка в другом цвете.
- **Заказы.** Новые выделены. У каждого заказа два номера: заказчика (часто иностранный, по нему
  подтверждаете) и получателя (кто примет и оплатит). Кнопки звонка и WhatsApp рядом.
  Статусы: Новый → Подтверждён → В доставке → Выполнен.

## Устройство
- `public/js/textures.js` — плитка (фото или имитация) и раскладки: прямая, вразбежку, диагональ, ёлочка.
- `public/js/plan.js` — план пола любой формы: готовые формы (в т.ч. «комната + коридор»),
  углы, изломы, длины стен, тип каждой стены (стена, проём без двери, дверь);
  подсчёт целых и подрезанных плиток, подбор сдвига раскладки.
- `public/js/scene3d.js` — 3D на three.js: свет, тени, отражения, рельеф швов, мебель;
  ракурсы «Обзор», «Сверху», «Изнутри» (на уровне глаз, несколько точек).
- `public/js/app.js` — конструктор, расчёт, каталог, корзина и оформление заказа.
- `public/js/admin.js`, `public/admin.html` — админка.
- `server.js` — сервер и API; данные в JSON-файлах (`data/`), запись атомарная.
- `public/vendor/three.bundle.js` — three.js r170 (MIT, см. `public/vendor/three.LICENSE`).

## Как считается
- **Пол** — по настоящей раскладке на плане: каждая плитка, которая хоть частично попадает
  в комнату, считается целой, плюс 3% на бой; коробки — по штукам в коробке.
- **Стены** — по площади стен (проёмы не считаются, дверь вычитается) с запасом 10–15%.
- **Цены в заказе** сервер всегда пересчитывает сам по своим ценам, цифрам из браузера не доверяет.
